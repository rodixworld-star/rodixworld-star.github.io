# BLACK ARCHIVE 🕯️

A web application for sharing dark fantasy, horror, thriller, and sci-fi web novels.

## Features
- **Live Story Publishing:** Upload custom images or direct web links and submit stories live.
- **Cloud Sync:** Keeps uploaded content synchronized across devices.
- **Multi-language Support:** Toggle between English and Korean.
- **Story Reader & Bookmarks:** Custom modal reader, bookmarking system, and export/import functionality.

## Deployment
Hosted on Vercel and indexed on Google Search via Google Search Console.
